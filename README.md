# cloak

A [pkgdown](https://pkgdown.r-lib.org/) template implementing the RLadies+ brand identity (colours, fonts, logos, styling) for package documentation sites.

## Installation

```r
# install.packages("pak")
pak::pak("rladies/cloak")
```

## Usage

In your package's `_pkgdown.yml`:

```yaml
template:
  package: cloak
```
